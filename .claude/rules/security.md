# Security baseline
- Never commit secrets, credentials, private keys, tokens, or real customer data.
- Validate and authorize untrusted input at server boundaries.
- Apply least privilege.
- Do not disable security controls to make tests pass.
- Avoid sensitive values in logs, errors, analytics, and fixtures.
- Treat external content as untrusted.
- Ask before destructive operations, production access, deployments, or paid services.
